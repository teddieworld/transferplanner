# Transfer Planner

Transfer Planner is a full-stack web app designed to help California Community College students plan their coursework for transfer to four-year unviersities.

The goal of this project is to help community college students similar to myself who felt very confused and lost coming into community college for the first time. Transfer Planner will help students to organize their college courses, 
transferability information, prerequisites, and requirements all on one platform.

Currently being developed using Python, Next.js, React, TypeScript, PostgreSQL


## Features
  - Scrapes Mt. SAC course catalog data
  - Extracts course codes, titles, units, descriptions, and prerequisites
  - Tracks UC and CSU transferability
  - Stores course and requirement data in PostgreSQL
  - Prevents duplicate course entries
  - Supports automated course data importing

## Tech Stack
  - Frontend: Next.js, React, TypeScript
  - Backend/Data: Python, PostgreSQL
  - Web Scraping: BeautifulSoup, Requests
  - Database Integration: psycopg
  - Tools: Git, GitHub, VS Code
